\section{解答の組み立て}

思いついた変形を,答案として読める解答へまとめるには,
「候補を作ること」と「候補を証明すること」を分けるとよい.

\subsection{候補を作る}

候補は,次の三つの情報から作る.

\begin{enumerate}
  \item 初項がどの数や関数に見えるか.
  \item 漸化式の右辺が,どの公式の右辺に似ているか.
  \item 置換後の表現が,次の段階でも保たれるか.
\end{enumerate}

例えば,
\[
  a_1=\frac{\sqrt{3}}{2},\qquad
  a_{n+1}=2a_n^2-1
\]
では,初項と倍角公式から
\[
  a_n=\cos\theta_n,\qquad
  \theta_1=\frac{\pi}{6},\qquad
  \theta_{n+1}=2\theta_n
\]
を考える.したがって候補は
\[
  a_n=\cos\left(2^{n-1}\frac{\pi}{6}\right)
\]
となる.

\subsection{帰納法で確認する}

上の候補を確認する場合,次の三段階を書く.

\begin{enumerate}
  \item $n=1$ で初項に一致することを示す.
  \item $a_n$ が候補の形だと仮定する.
  \item 漸化式に代入し, $n+1$ の候補を得る.
\end{enumerate}

実際,
\begin{align*}
  a_{n+1}
    &=2a_n^2-1\\
    &=2\cos^2\left(2^{n-1}\frac{\pi}{6}\right)-1\\
    &=\cos\left(2^n\frac{\pi}{6}\right).
\end{align*}
これで候補が漸化式を満たすことが分かる.

\subsection{計算を始める前に戻る}

変形後に式が複雑になったら,そのまま押し切らない.次の三つを確認する.

\begin{enumerate}
  \item 新しい変数は,元の式より本当に単純か.
  \item 次の項を作っても,同じ表現が保たれるか.
  \item 初期条件を新しい変数で書けるか.
\end{enumerate}

例えば,三角関数の置換で分母が0になるなら,公式が見つかっただけで,
数列全体の解法になっているとは限らない.また,
\[
  \left(u+u^{-1}\right)^2-1=u^2+u^{-2}+1
\]
のように余分な項が出るなら,その対称式は閉じていない.

\subsection{一般項が出ないときの答案}

一般項が得られない場合でも,答案は次の順で組み立てられる.

\begin{enumerate}
  \item 不動点を求める.
  \item 初項から数項を計算する.
  \item 単調性と有界性を調べる.
  \item 収束するなら極限を不動点の方程式で決める.
  \item 必要なら誤差や周期性を調べる.
\end{enumerate}

\begin{quote}
「一般項がない」ことと「何も分からない」ことは同じではない.
漸化式が作る動きを,閉じた式とは別の言葉で記述できる.
\end{quote}

\subsection{最後の五行}

\begin{enumerate}
  \item 初項を使ったか.
  \item 変形の途中で割った量が0にならないか.
  \item 定義できない項を生んでいないか.
  \item 候補は漸化式を満たすか.
  \item 求めた式から,問題が尋ねた量を読み取ったか.
\end{enumerate}
